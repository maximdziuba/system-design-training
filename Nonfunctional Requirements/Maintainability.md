# Maintainability

## Key Points

- **Operability** (observability, alerting, automatic rollbacks)
- **Simplicity** (clean code and architecture, min. workarounds)
- **Changeability** (modularity, weak connections, easy integrations, easy replacing of components)

## How to Measure

Through MTTR (mean time to repair) and metrics:
- Time to localize the error
- Time to fix
- Amount of auto-rollbacks

## How to Enhance It

- Invest in tools (logging, traces, metrics)
- Document procedures
